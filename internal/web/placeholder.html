The binary was compiled without a Next.js export embedded in it. Build it:

npm --prefix web install     # once
npm --prefix web run build
go build ./...

This is the expected state on a fresh clone. go build ./... deliberately succeeds without the UI so that every commit builds on its own — the API below is complete and working.
